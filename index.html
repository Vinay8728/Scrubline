Quality lock: Resolution is never changed — width and height stay exactly as uploaded. PNG and WebP output is lossless. JPEG output is re-encoded at maximum quality (100%), so there is no visible or measurable quality loss. The "reset pixel fingerprint" toggle is off by default precisely so pixels are left 100% untouched.

What this can and can't do: Scrubline removes metadata stored as separate data inside the file — EXIF, GPS, XMP/IPTC, PNG text chunks, and markers used by tools like Automatic1111 or ComfyUI. It cannot remove anything baked into the pixels themselves, such as an invisible watermark, and it can't guarantee how any platform's classifier will read the resulting image.
